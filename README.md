# Лабораторная работа: Разработка графического интерфейса для языкового процессора

## Название и цель работы
**Название:** GUI для языкового процессора – текстовый редактор с расширенными возможностями.  
**Цель:** Создание кроссплатформенного графического интерфейса для языкового процессора в виде специализированного текстового редактора, который в дальнейшем будет расширен до полноценного анализатора исходного кода.

## Описание проекта
Разработано приложение – текстовый редактор на платформе WPF (.NET). Редактор поддерживает:
- Работу с несколькими документами (вкладки).
- Стандартные операции с текстом (создание, открытие, сохранение, вырезание, копирование, вставка, отмена/повтор).
- Настройку размера шрифта (предопределённые значения или пользовательский ввод).
- Нумерацию строк и подсветку синтаксиса C#.
- Перетаскивание файлов в окно.
- Строку состояния, отображающую имя текущего файла, количество символов/строк, позицию курсора и текущий размер шрифта.
- Локализацию интерфейса на русский, английский и монгольский языки.
- Горячие клавиши для всех основных команд.
- Окна справки (описание функций) и «О программе».
- Таблицу вывода ошибок (подготовлена для интеграции с языковым процессором).

Интерфейс включает главное меню, панель инструментов, область редактирования с вкладками, таблицу ошибок и строку состояния.

## Используемые технологии
- **Язык программирования:** C# (.NET Framework 4.7.2)
- **Фреймворк GUI:** WPF (Windows Presentation Foundation)
- **Среда разработки:** Microsoft Visual Studio 2026

## Инструкция по сборке и запуску

### Установка зависимостей
Проект использует NuGet-пакет `AvalonEdit`. При сборке в Visual Studio пакет должен быть загружен автоматически.

### Сборка проекта
1. Откройте решение в Visual Studio.
2. Убедитесь, что выбран режим сборки `Release` или `Debug`.
3. Нажмите **Собрать → Собрать решение** (или `Ctrl+Shift+B`).
4. Готовый исполняемый файл появится в папке:
   - `bin\Release\` (для Release-сборки)
   - `bin\Debug\` (для Debug-сборки)

### Запуск приложения
- Дважды щёлкните `WpfApp1.exe` в папке сборки.
- Или запустите отладку из Visual Studio (F5).

### Функции и способы вызова

#### Работа с файлами
| Функция       | Меню                 | Кнопка панели | Горячие клавиши |
| ------------- | -------------------- | ------------- | --------------- |
| Создать       | Файл → Создать       | Создать       | `Ctrl+N`        |
| Открыть       | Файл → Открыть       | Открыть       | `Ctrl+O`        |
| Сохранить     | Файл → Сохранить     | Сохранить     | `Ctrl+S`        |
| Сохранить как | Файл → Сохранить как | –             | `Ctrl+Shift+S`  |
| Выход         | Файл → Выход         | –             | `Ctrl+Q`        |

#### Редактирование текста
| Функция      | Меню                  | Кнопка панели | Горячие клавиши |
| ------------ | --------------------- | ------------- | --------------- |
| Отменить     | Правка → Назад        | Назад         | `Ctrl+Z`        |
| Повторить    | Правка → Заново       | Вперёд        | `Ctrl+Y`        |
| Вырезать     | Правка → Вырезать     | –             | `Ctrl+X`        |
| Копировать   | Правка → Копировать   | Копировать    | `Ctrl+C`        |
| Вставить     | Правка → Вставить     | Вставить      | `Ctrl+V`        |
| Удалить      | Правка → Удалить      | –             | `Delete`        |
| Выделить всё | Правка → Выделить всё | –             | `Ctrl+A`        |

#### Настройка текста
| Функция                  | Меню                            |
| ------------------------ | ------------------------------- |
| Изменение размера шрифта | Текст → Размер шрифта → выбор   |
| Другой размер шрифта     | Текст → Размер шрифта → Другой… |

#### Справка и информация
| Функция       | Меню                    |
| ------------- | ----------------------- |
| Вызов справки | Справка → Вызов справки |
| О программе   | Справка → О программе   |

### Дополнительные возможности
- **Перетаскивание файлов:** файлы можно перетащить из проводника в окно приложения – они откроются в новой вкладке.
- **Вкладки:** создание нового документа добавляет вкладку. Закрыть вкладку можно кнопкой с красным квадратиком на её заголовке.
- **Строка состояния:** динамически отображает имя файла, количество символов, строк, позицию курсора и текущий размер шрифта. При переключении между вкладками данные обновляются.
- **Локализация:** в меню **Справка → Язык** можно выбрать русский, английский или монгольский язык.
- **Изменение размера шрифта:** применяется ко всем открытым редакторам и к таблице ошибок одновременно.
- **Таблица ошибок:** в текущей версии таблица готова для вывода ошибок
